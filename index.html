Installation

Installing in four steps

Android blocks apps from outside the Play Store by default, so you'll grant permission once.

  1. Tap Download APK above and wait for the file to finish saving.
  2. Open it from your notification shade or the Downloads folder. Android will warn that this app came from an unknown source.
  3. Choose Settings in that prompt and turn on Allow from this source for your browser or file manager, then go back.
  4. Tap Install, then Open. Register an account on first launch and you're ready to sell.

A note on this build: this is a development build of the app, signed with a debug key rather than a release key. It installs and runs normally, but it isn't hardened for production use — so avoid putting real customer or payment data into it until a signed release build is available. It also needs an internet connection, since products and transactions are stored on a hosted backend.

FAQ

Common questions

Is POS System free?

Yes. The APK is a free download with no ads, no trial timer, and no in-app purchases.

Why isn't it on the Play Store?

It's distributed directly as an APK, which is why you install it manually with the steps above. Nothing else about the app changes.

Will it run on my phone?

If your device runs Android 7.0 (Nougat) or newer, yes. The build is universal, so it works across phone processors without picking a special version.

Does it work offline?

No. Your catalog and sales are kept on a cloud backend, so the app needs an internet connection to sign in, load products, and save transactions.

What permissions does it ask for?

Only internet access, for talking to that backend. It doesn't request your camera, location, contacts, files, or SMS.

Where is my data stored?

On the app's hosted backend, tied to the account you register. Signing in on another Android device brings the same catalog and history with you.

How do I update later?

Download the newer APK from this page and install it over the top. Installing a build signed with the same key keeps your existing setup in place.
